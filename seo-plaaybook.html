Audit SEO Awal

Situs audit — temukan masalah yang menghambat ranking

▼

🔍 Apa Itu SEO Audit?

SEO audit adalah pemeriksaan menyeluruh terhadap website untuk menemukan masalah teknis, konten, dan off-page yang menghambat ranking di Google. Audit harus dilakukan secara berkala (minimal 1x per bulan).

🛠 Tools yang Dibutuhkan

ToolFungsiBiaya
Google Search ConsolePerformance data, indexing, errorsGratis ✓
Google Analytics 4Trafil user behavior, konversiGratis ✓
Google PageSpeed InsightsCore Web Vitals, performa loadingGratis ✓
Ahrefs / SEMrushBacklink audit, competitor analysisBerbayar
Screaming FrogCrawl technical issuesGratis ≤500 URL

📊 Interpretasi Data GSC (Dashboard Ini)

Gunakan dashboard SEO untuk memantau performa. Perhatikan metrik ini:

  • CTR rendah (<2%) → Judul/meta description perlu optimasi. Klik perlu lebih menarik.
  • Posisi tinggi (>10) tapi banyak tayangan → Konten relevan tapi kurang kompetitif. Perlu perkuat konten & backlink.
  • Banyak klik di branded query → Bagus, brand awareness kuat. Sekarang fokus non-brand keywords.
  • CTR tinggi tapi posisi rendah → Potensi besar! Naikkan posisi = klik naik drastis.
⚠️ Red Flags — Perlu Perhatian Segera

CTR <1% untuk keyword branded ("golden studio"). Jika ini terjadi, kemungkinan judul meta atau featured snippet pesaing lebih menarik.

✅ Audit Checklist

  • Cek mobile-friendliness (80%+ traffic dari HP)Penting

On-Page SEO

Optimasi elemen di dalam halaman — judul, deskripsi, konten, struktur

▼

📌 Title Tag — Paling Penting

Title tag adalah hal pertama yang dilihat user di Google. Ini menentukan apakah mereka klik atau skip.

// Formula Title Tag Golden Studio: [Layanan] + [Lokasi] | Golden Studio // Contoh: Foto Profesional Cikarang — Harga Mulai 50rb | Golden Studio Studio Foto Bekasi untuk Wisuda & Prewedding | Golden Studio Sewa Studio Foto Cikarang — Full Backdrop & Pencahayaan | Golden Studio
💡 Aturan Title Tag

Panjang optimal: 50-60 karakter. Selalu sisipkan keyword utama di awal. Sertakan lokasi (Cikarang/Bekasi) untuk local SEO. Gunakan angka atau harga untuk meningkatkan CTR.

📝 Meta Description — Iklan Gratis

Meta description tidak langsung mempengaruhi ranking, tapi menentukan CTR. Ini "iklan" Anda di Google.

// Formula Meta Description: [Problem/Apa yang dicari] + [Solusi/Social proof] + [CTA] // Contoh (maks 155 karakter): Cari studio foto profesional di Cikarang? Golden Studio sediakan foto wisuda, profil, produk, keluarga. 1000+ klien puas. Book sekarang!

🏗 Struktur Heading (H1-H6)

  • H1 — 1 per halaman, berisi keyword utama (contoh: "Foto Profesional Cikarang — Golden Studio")
  • H2 — Sub-topik utama (contoh: "Layanan Kami", "Harga Foto Wisuda")
  • H3 — Detail sub-topik (contoh: "Paket Foto Keluarga", "Paket Foto Produk")
  • H4-H6 — Jarang diperlukan, gunakan untuk struktur konten panjang

🖼 Gambar — Optimasi & Alt Text

  • Gunakan format WebP atau JPG compressed (maks 200KB per gambar)
  • Nama file deskriptif: foto-wisuda-cikarang-golden-studio.webp (bukan IMG_20260901.jpg)
  • Alt text harus deskriptif: "Contoh foto wisuda di Golden Studio Cikarang — jasa fotografi profesional"
  • Tambahkan caption/teks di bawah gambar untuk konteks SEO

🔗 Internal Linking

Setiap halaman harus punya minimal 3 internal link ke halaman lain di website. Ini membantu Google memahami struktur situs dan menyebarkan "link juice".

  • Halaman "Layanan Foto Wisuda" → link ke "Portofolio Wisuda", "Harga", "Cara Order"
  • Blog post "Tips Foto Profil LinkedIn" → link ke "Layanan Foto Profil"
  • Homepage → link ke semua halaman layanan utama

✅ On-Page Checklist

  • Set title tag unik untuk setiap halaman (50-60 karakter, ada keyword + lokasi)Wajib
  • Set meta description unik per halaman (140-155 karakter, ada CTA)Wajib
  • Struktur heading benar: 1x H1, H2 untuk sub-topik, H3 untuk detailWajib
  • Semua gambar punya alt text deskriptif + nama file SEO-friendlyPenting

📍 Google Business Profile (GBP) — Langkah Wajib

GBP (dulunya Google My Business) adalah aset #1 untuk local SEO. Ini yang muncul di Google Maps.

Technical SEO

Performa website: kecepatan, mobile, struktur, crawlability

▼

⚡ Core Web Vitals — Target Google

Google menggunakan metrik ini untuk ranking. Semua harus "Hijau" (baik):

MetricTargetApa Ini
LCP (Largest Contentful Paint)<2.5 detikWaktu konten utama muncul
FID (First Input Delay)<100msRespon saat user pertama klik
CLS (Cumulative Layout Shift)<0.1Seberapa stabil layout saat loading

🔧 Quick Wins — Tingkatkan Kecepatan

  • Compress semua gambar → pakai WebP atau TinyPNG (target <200KB per gambar)
  • Enable caching → browser cache <1 minggu untuk aset statis
  • Minify CSS & JS → hapus whitespace, gunakan minified version
  • Lazy loading → gambar baru load saat user scroll ke bawah
  • CDN → gunakan Cloudflare untuk cache global

📱 Mobile-First Indexing

Google sekarang menggunakan versi mobile dari website untuk indexing. Pastikan:

  • Website responsif di semua ukuran layar
  • Teks cukup besar (min 16px) — tidak perlu zoom
  • Tombol & link cukup besar untuk diklik dengan jari
  • Tidak ada horizontal scroll (geser ke kanan)
  • Pop-up tidak menghalangi konten utama
⚠️ Cek Mobile di HP Beneran

Jangan hanya cek di DevTools Chrome. Buka website di HP Anda sendiri — scroll, tap, zoom. Rasakan apakah nyaman dipakai. Jika tidak nyaman untuk Anda, tidak nyaman untuk klien juga.

🗺 Sitemap & Robots.txt

  • Sitemap XML → kirim ke Google Search Console (opsional untuk website kecil, tapi membantu)
  • Robots.txt → pastikan tidak memblokir halaman penting dari crawling
  • HTTPS → wajib! Jika belum, enable di hosting/Cloudflare
  • Canonical URL → atur kanonik untuk hindiri duplikat konten

✅ Technical SEO Checklist

  • Cek PageSpeed Insights — semua halaman target hijau (>90 mobile)Wajib
  • Compress semua gambar ke WebP, max 200KBWajib
  • Website responsif — cek di HP asli, bukan hanya DevToolsWajib
  • HTTPS aktif di seluruh halamanWajib
  • Submit sitemap ke Google Search ConsolePenting
  • Fix semua error di GSC "Pages" → "Indexed" dan "Not indexed"Penting

Off-Page SEO & Backlink

Membangun otoritas website dari luar — link, mentions, PR

▼

🔗 Apa Itu Backlink?

Backlink adalah link dari website lain ke website Anda. Google menganggap backlink sebagai "vote of confidence". Semakin banyak backlink berkualitas, semakin tinggi ranking.

💡 Kualitas > Kuantitas

1 backlink dari website kampus atau media lokal Bekasi jauh lebih berharga daripada 100 backlink dari direktori spam. Fokus pada relevance dan authority.
